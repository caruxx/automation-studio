        手順: ① VPS（Ubuntu/Debian）の情報を入力 → ② root パスワードを入力して「セットアップ実行」。SSH 鍵の生成・登録、ffmpeg / screen の導入、配信スクリプトの配置まで自動で行います（再実行しても安全）。パスワードは鍵登録にのみ使用し保存されません。
