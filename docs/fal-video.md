# fal H3 動画連携

Automation Studioの右上「fal 動画」、または動画詳細の画像タブ「fal 動画」から開く任意の追加機能。従来のレイヤーモーション、PNG制作、制作モード、チャンネルの非表示は継続する。

Macが操作・履歴・取得・FFmpeg整形を担当し、生成の計算は公式falクラウドAPIで行う。別の自己管理Cloudサーバーは不要。新しい外部サービスの契約、キーの発行・永続保存、追加チャージはこの実装に含めない。

## 画面と保存

キーはサーバーの実行環境に本人が設定する。通常の有料送信は既定で無効で、承認後の実行環境だけに `APP_FAL_PAID_SUBMIT_ENABLED=1` を設定する。キーを共有設定・画面・APIリクエストへ貼り付けない。

通常画面ではPNGを選ぶだけでは転送しない。SHA-256と寸法をローカルで確認し、転送を明示操作する。Wobbleの3案は指定原本のハッシュ一致を必要とする。見積り保存はローカルのみ。見積りの画像URL・開始終了画像・詳細プロンプト・期限・予約額を確認してから明示的に1回送信する。

履歴は既存のMacプロファイル設定フォルダ下 `fal-video/history.sqlite3`、MP4は同じ専用フォルダの `exports/`。`APP_FAL_RUNTIME_ROOT` が指定されればその絶対パスを使用する。採用元PNGや既存プロジェクトを上書きしない。画面から元MP4を保存でき、1280×720版は元映像の寸法・尺を保ちながら縮小・余白調整する。元映像が1280×720未満なら自動アップスケールしない。

## 操作契約と確認

有料POSTは1ジョブ1回。クライアントの自動再送とfal側の自動リトライを無効にし、`X-Fal-No-Retry: 1` を付ける。送信前に履歴を保存し、結果不明の場合は再送せず公式履歴と同じジョブを照合する。生成状況更新・既存ジョブの素材取得再実行は新しい生成依頼ではない。キャンセル受付は実行中生成の停止・無課金・返金を保証しない。

技術確認済みの取得と目視採用判定を区別する。全編復号、実寸法・尺・SHA確認に加え、5匹それぞれの動作、手と楽器の接触、鼻・目・ヒゲ・体格、雀の実際の背面ターン、始終点と速度・継ぎ目を確認してから採否を報告する。未完了・不採用の以前の02/03を新しい成功例として扱わない。目視前の出力を自動採用しない。
